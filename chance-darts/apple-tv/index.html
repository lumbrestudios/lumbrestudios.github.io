Free TV receiver. Requires a compatible scorer for live viewing.

THE ROOM.THE MATCH.THE MOMENT.CHANCE DARTS / LUMBRE STUDIOS

GET CONNECTED.

  1. Install the receiver

    Download Chance Darts Live Display from the Apple TV App Store. It is a separate, free app for compatible Apple TV devices.

  2. Start on the scorer

    Open Match Play or Darts Night in Chance Darts and start remote Live Display. Keep the scoring app open and connected.

  3. Pair with your display code

    Enter the scorer’s code on Apple TV. Scores update as you enter them on the scoring device. Live viewing needs internet access.

Made to be watched.

Large scores and a clear active-player indicator keep the room with the match. Follow leg and set progression, recent visits, checkout suggestions and the performance information sent by the scorer.

The match in context

Three-dart averages, 180s, highest checkouts and dedicated result screens add detail around the score.

The whole darts night

Current fixtures, upcoming matches, running order, standings and highlights carry the event from its opening match to the final results.

A companion for the room.

The TV app displays a match controlled by Chance Darts on a compatible scoring device. It does not create matches or accept score entry.

Simple receiver controls

Use Back / Menu for Continue Watching, Change Display Code or Exit Live Display. Leaving this TV display does not stop scoring or other spectators.

Try the view first

Try Demo presents fictional scores and Darts Night screens locally, without connecting a scorer. No separate account or in-app purchase is required in the TV app.
