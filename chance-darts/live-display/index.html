Live Display

YOUR MATCH.
A BIGGER STAGE.

Keep the scoring device in your hands. Put the action where everyone can see it, from the home setup to the pub darts night.

Open browser Live Display

Free to download. Optional lifetime Pro.

GET CONNECTED.

  1. Start the display

    Open a supported Match Play game or Darts Night. Choose Live Display, then Start Live Display for the remote receiver.

  2. Open a receiver

    Open the browser receiver on your second screen, or use the native Chance Darts Live Display app on Apple TV.

  3. Enter the display code

    Use the eight-character code from the scorer. Keep entering scores on that device while the receiver follows. Share the code only with intended viewers.

One scorer. More spectators.

The display follows the match information sent by the scoring device: scores, active player, legs, sets and available performance details. In Darts Night, follow the current fixture, running order, standings and highlights.

Browser Live Display

Use a compatible connected browser. The receiver is already available at chancedarts.lumbrestudios.app. It is a spectator screen and cannot enter scores.

Native Apple TV

A dedicated television experience with remote-friendly controls, results and a built-in offline demo. Install the free receiver separately.

Choose your screens.

Duo outer-screen presentation is a separate local destination. It can run alongside browser and Apple TV receivers, with independent local and remote controls.

Local Duo

Ordinary Match Play and Darts Night can appear outside while you score inside. This local display works offline and needs no pairing code; camera permission is required.

Keep the night moving

Darts Night display can continue between fixtures and into a rematch night. Use Stop Display when the broadcast should end. A disconnected receiver may retain older scores while reconnecting.
